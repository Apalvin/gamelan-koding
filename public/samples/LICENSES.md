# Lisensi dan Atribusi Sampel Audio Gamelan

Dokumen ini mencatat lisensi dan atribusi seluruh berkas audio sampel yang digunakan dalam aplikasi Gamelan Koding.

## Kebijakan Sampel
1. Hanya sampel rekaman milik sendiri atau sampel berlisensi bebas (Creative Commons / Public Domain) yang diperbolehkan.
2. Setiap sampel harus mencantumkan sumber, lisensi asli, dan nama perekam/pengrawit (jika diketahui).
3. Jika sampel audio eksternal tidak tersedia atau belum dimuat, aplikasi secara otomatis menggunakan sintesis prosedural Web Audio API tingkat lanjut sebagai fallback.

## Berkas Sampel
- Status saat ini: Belum ada sampel pihak ketiga yang disertakan. Aplikasi menggunakan engine sintesis multi-osilator inharmonik Web Audio API bawaan.
- Praktisi karawitan atau kontributor dapat menambahkan sampel berlisensi bebas ke dalam direktori ini dengan format WAV/OGG/MP3.
